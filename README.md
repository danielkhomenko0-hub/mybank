# MyBank — прототип децентрализованного банка

Учебный прототип кредитного протокола (по модели Aave/Compound): люди кладут токены под процент, другие берут кредиты под залог, ставки определяются загрузкой пула, плохие кредиты закрываются ликвидаторами, а часть процентов идёт «банку» в резервы.

> ⚠️ Это прототип для обучения и портфолио. Код не проходил аудит. Не разворачивай его в mainnet с реальными деньгами и не принимай чужие средства — в UK это регулируемая деятельность.

## Архитектура

```
                ┌──────────────────────────┐
  Вкладчики ──► │                          │ ◄── Заёмщики
  deposit /     │       LendingPool        │     borrow / repay
  withdraw      │                          │
                │  • учёт долей (shares)   │ ◄── Ликвидаторы
                │  • начисление процентов  │     liquidate
                │  • health factor         │
                │  • резервы банка         │ ──► Казна (withdrawReserves)
                └────────────┬─────────────┘
                             │ getPrice()
                     ┌───────▼────────┐
                     │  SimpleOracle  │  (в продакшене — Chainlink)
                     └────────────────┘
```

| Контракт | Роль в «банке» |
|---|---|
| `LendingPool.sol` | Ядро: вклады, кредиты, проценты, ликвидации, резервы |
| `SimpleOracle.sol` | Цены активов в USD (вручную, для тестнета) |
| `TestToken.sol` | Тестовые USDC и WETH с открытым `mint` |
| `TetherLikeToken.sol` | Тестовый USDT, который ведёт себя как настоящий: переводы без `return`, разрешение меняется только через ноль |
| `frontend/` | Веб-интерфейс банка: демо-режим (симуляция в браузере) и режим кошелька (MetaMask) |
| `scripts/deploy.js` | Деплой всего банка в сеть, адреса сохраняются в `deployments/` |
| `scripts/liquidator.js` | Бот-ликвидатор: находит заёмщиков по событиям и ликвидирует счета с HF < 1 |
| `.github/workflows/` | Автоматические тесты и публикация сайта на GitHub Pages |

## Как это работает — банковская логика в коде

**Вклады.** При депозите пользователь получает «доли» пула. Доли не меняются, а стоимость каждой растёт, когда заёмщики платят проценты. Так же работают паевые фонды.

**Кредиты под залог.** Все депозиты пользователя считаются залогом. Сколько можно занять, задаёт LTV рынка: под USDC — 80%, под USDT и ETH — 75%. 1 ETH по $2000 даёт лимит $1500. USDT получает более строгие параметры, чем USDC, из-за более высокого риска эмитента.

**Ставка «с изломом» (kink).** Ставка зависит от загрузки пула U = выдано / всего денег:
- до 80% растёт плавно: `base + slope1 × U / kink`;
- после 80% резко дорожает: `+ slope2 × (U − kink) / (1 − kink)`.

Так протокол сам стимулирует возврат ликвидности, без управляющего. Ставка по вкладам равна `ставка по кредиту × U × (1 − доля банка)`.

**Health factor.** `HF = Σ(залог × порог ликвидации) / долг`. Если HF < 1, кредит можно ликвидировать.

**Ликвидация.** Любой может погасить до 50% долга проблемного заёмщика (close factor) и получить его залог с бонусом 5%. Пример из тестов: ETH падает до $1800, ликвидатор гасит $750 и получает 0.4375 ETH стоимостью $787.50.

**Доход банка.** 10% всех процентов (reserve factor) идут в резервы. Владелец выводит их в казну через `withdrawReserves`.

**Защиты.** Защита от повторного входа (reentrancy guard). Округление всегда в пользу пула. Учёт ликвидности ведётся по внутренним счётчикам, а не `balanceOf`, поэтому «подаренные» токены не ломают расчёт. Параметры риска проверяются при листинге: LTV < порог, порог × (1 + бонус) ≤ 100%.

## Запуск и тесты

```bash
npm install
npm test        # компиляция, сборка интерфейса и 25 тестов
```

Что проверяют тесты:
- **контракт (12)**: вклады, лимиты LTV, нехватка ликвидности, проценты за год, излом ставки, запрет вывода залога, ликвидации, полное погашение, резервы, параметры админа, работа с USDT-подобным токеном;
- **движки интерфейса (7)**: симулятор в браузере считает проценты и ликвидации так же, как контракт; блокчейн-движок работает с настоящим контрактом и сам обнуляет разрешение для USDT; `deployBank` разворачивает рабочий банк;
- **бот-ликвидатор (1)**: находит заёмщика по событиям, не трогает здоровый счёт, ликвидирует после падения цены;
- **страница (5)**: открывается без ошибок, кнопки работают, сценарий «обвал ETH → ликвидация → прибыль банка», подключение кошелька и вклад через контракт, деплой банка кнопкой на странице. Тест подключения кошелька требует запущенной локальной цепочки, иначе он пропускается.

## Интерфейс

У страницы два режима:
- **Демо.** Банк считается прямо в браузере по формулам контракта. Можно двигать цену ETH, перематывать время, запускать бота-ликвидатора и забирать прибыль банка. Работает без кошелька.
- **Кошелёк.** Подключение MetaMask к развёрнутым контрактам. Есть кран тестовых токенов, вклады и кредиты идут настоящими транзакциями. Владельцу банка доступны смена цены ETH и вывод резервов.

### Попробовать локально (без Sepolia)

```bash
npm run chain                       # терминал 1: локальная цепочка на :8545
# терминал 2: ключ тестового аккаунта печатается в терминале 1
RPC_URL=http://127.0.0.1:8545 PRIVATE_KEY=<ключ из терминала 1> NETWORK=localhost npm run deploy
npm run build:web
npx serve dist                      # открыть http://localhost:3000
```

В MetaMask добавьте сеть `http://127.0.0.1:8545` (chainId 1337) и импортируйте тот же тестовый ключ.

## Деплой в Sepolia

**Проще всего — со страницы.** Откройте сайт банка в Chrome с MetaMask, переключите MetaMask на сеть Sepolia, выберите режим «Кошелёк» и нажмите «Развернуть банк через MetaMask». Будет 11 подтверждений, приватный ключ никуда вставлять не нужно. Страница покажет адреса: сохраните их в `deployments/sepolia.json` и закоммитьте, чтобы банк увидели все.

**Через терминал:**

1. Создайте **отдельный** кошелёк в MetaMask только для тестов. Ключ от основного кошелька не используйте никогда.
2. Возьмите тестовые ETH в любом Sepolia faucet. На деплой нужно примерно 0.05 ETH.
3. Получите RPC-адрес Sepolia (бесплатно у Alchemy, Infura или в публичных списках RPC).
4. Выполните:
   ```bash
   RPC_URL=https://... PRIVATE_KEY=0x... npm run deploy
   npm run build:web
   ```
5. Адреса окажутся в `deployments/sepolia.json`. Закоммитьте этот файл: GitHub сам пересоберёт сайт, и режим «Кошелёк» начнёт работать с Sepolia. Ключ в git не попадёт, передавайте его только через переменную окружения.

## Бот-ликвидатор

```bash
RPC_URL=https://... PRIVATE_KEY=0x... NETWORK=sepolia npm run liquidator
```

Бот раз в 30 секунд проверяет всех заёмщиков (`INTERVAL` меняет паузу, `ONCE=1` делает одну проверку). Если health factor ниже 1, бот гасит половину самого крупного долга и забирает залог с бонусом 5%. На тестнете он сам печатает себе тестовые токены для погашения (`AUTO_MINT=0` отключает). Используйте для бота отдельный тестовый кошелёк.

## Публикация на GitHub

1. Зарегистрируйтесь на github.com и установите [GitHub Desktop](https://desktop.github.com).
2. В GitHub Desktop: **File → Add local repository** → выберите папку `mybank` (это уже git-репозиторий с первым коммитом).
3. Нажмите **Publish repository**, снимите галочку «Keep this code private», если хотите показывать проект работодателям.
4. На сайте GitHub откройте репозиторий → **Settings → Pages** → в поле **Source** выберите **GitHub Actions**.
5. Через пару минут сайт появится по адресу `https://<ваш-логин>.github.io/mybank/`. Вкладка **Actions** показывает, что тесты прошли.

## Чего пока нет (осознанно)

- **Плохие долги (bad debt).** Если залог упал сильнее долга, остаток никто не покрывает. В Aave для этого есть страховой модуль.
- **Реальный оракул.** Нужен Chainlink, проверка устаревания цены и защита от манипуляций.
- **Выбор залога.** Сейчас все депозиты считаются залогом, отключить актив нельзя.
- **Управление.** Админ — один кошелёк. В продакшене это мультисиг, таймлок и, возможно, DAO.
- **Пауза и аварийная остановка.**
- **Аудит и формальная верификация.**
